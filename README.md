# dotfiles

My dotfiles repo.


## Requirements

* git
* zsh
* fzf
* curl


### Notes

After installing `fzf` with homebrew, to set up shell integration, see:
  https://github.com/junegunn/fzf#setting-up-shell-integration


## Installation

```bash
./install.sh
```

### Installing pi

After installing the dotfiles, open a new terminal and run:

```bash
pi_utils setup
```
